# Simple Polymorphism practice

## Overview

## Key Concepts
**User Input:** Prompts the user to enter `1` for a Cat or `2` for a Dog, reading the input via `Scanner`.

**Dynamic Instantiation:** Based on the choice, it assigns either a `Cat` or `Dog` object to a shared `Pet` interface reference (defaulting to a `Cat` if the input is invalid).

**Polymorphic Execution:** Calls `pet.eat()` and `pet.playToy()`, executing the specific class implementation corresponding to the selected pet type at runtime.
